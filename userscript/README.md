# BlockClip to ZIP 油猴脚本 (Tampermonkey Userscript) v2.1.2

专为 **Google Gemini** (`gemini.google.com`) 与 **Google AI Studio** (`aistudio.google.com`) 深度定制的代码还原、智能打包与极速上传增强脚本。

---

## 🌟 核心特性

### 1. 📂 目录层级还原与双模式导出
- **智能 Markdown 切割还原**：精准提取 `File: path/to/file.ext` 及其代码围栏，按相对路径中的 `/` 自动还原深层级文件夹。
- **自适应代码围栏防截断**：识别连续多反引号（```` ``` ````），确保内嵌 Markdown 或代码块的文件内容不被误截断。
- **代码切片智能合并**：同一文件的多个片段（如 `lines 10-25`、`lines 50-80`）自动合并入同一文件，并注入规范的语言注释分隔。
- **双导出模式随心切换**：
  - **📦 ZIP 压缩包模式**：基于 `JSZip`（主引擎）在内存中极速压缩；若遇 CDN 故障，自动无缝降级至**内置零依赖 PKZIP STORE 引擎**，保障 100% 可用。
  - **📄 单文件 .md 模式**：自动构建带 ASCII 目录树、各文件自适应围栏的代码合集包，**完美绕过 Gemini 针对 ZIP 压缩包内文件数量的上传限制**。

### 2. 🖱️ 丝滑拖拽与多通道附件注入引擎
- **半透明穿透拖拽桥接（Drag Bridge）**：拖拽卡片时，悬浮面板下一帧自动变为半透明且事件穿透（`pointer-events: none`），彻底消除面板对下方聊天输入框的视线与鼠标遮挡。
- **免文本误粘贴**：`dragstart` 屏蔽纯文本污染，避免拖入输入框时光标处被写入文件名文字。
- **三级推进注入引擎**：
  1. 向编辑器分发原生的 `ClipboardEvent('paste')`（240ms 快速探测）；
  2. 自动匹配无后缀限制或接受 zip/md 的 `input[type="file"]` 并触发双事件；
  3. 目标 dropzone 异步派发 `dragenter -> dragover -> drop` 合成事件序列；
  4. **MutationObserver 真实反馈校验**：以页面是否真正生成附件 Chip、进度条作为注入成功的评判标准。

### 3. 🚀 极速直通与聊天框智能感知
- **一键直通**：**右键点击悬浮球** 或按全局快捷键 **`Alt + Shift + Z`**，不展开面板，直接从剪贴板读取代码、自动打包并注入当前对话框！
- **聊天框智能感知胶囊**：在 Gemini / AI Studio 聊天输入框内直接粘贴多文件 BlockClip 文本时，底部浮现轻量胶囊 **`[ ⚡ 转为附件注入 ]`**；点击后自动上传附件，并**智能清空聊天框内的冗长代码正文**（折叠比对，绝不误删用户自带的提示词）。
- **轻量瞬时重命名**：在卡片文件名输入框内改名直接复用已生成的 Blob，**0ms 瞬时改名**，无需二次压缩。

### 4. 🦊 全浏览器与平台兼容（Chrome / Edge / Firefox）
- **Firefox Xray Vision 深度穿透**：通过 `@grant unsafeWindow` 与内存克隆，在页面上下文中同域构造真实的 `PAGE_WIN.File` 与事件，彻底攻克 Firefox 油猴沙箱跨域派发事件被阻断的顽疾。
- **输入框 Focus 保护**：在卡片改名输入框内划选文字时，自动临时停用卡片的 `draggable="true"`，防止改名选区操作误触发卡片拖动残影。
- **跨平台滚动条与高敏防抖**：悬浮球拖拽采用 8px 位移防抖，兼容高 DPI 触摸板；自适应深浅色主题，样式兼顾 Chromium 与 Firefox。

### 5. 🛡️ 极致性能与安全防线
- **大文本内存直通（Memory Fast-Path）**：文本超过 250 KB 时自动进入内存直通区，文本框仅展示 2400 字符预览，杜绝大文本导致的 DOM 排版与卡顿。
- **敏感文件识别与一键排除**：自动检测 `.env`、`id_rsa`、证书、密钥文件，文件列表中醒目标记 `⚠️ 敏感`，并支持一键取消勾选。
- **100% 免疫 Trusted Types**：全生命周期严守 **零 `innerHTML`** 铁律，纯 DOM 原生 API 构建，完全免疫 Google 系列站点的 CSP 拦截。

## 🚀 安装步骤

1. **准备浏览器脚本管理器**：
   确保您的浏览器已安装以下任意一款脚本扩展：
   - [Tampermonkey (篡改猴)](https://www.tampermonkey.net/)
   - [Violentmonkey (暴力猴)](https://violentmonkey.github.io/)
   - [ScriptCat (脚本猫)](https://scriptcat.org/)

2. **安装脚本**：
   - 打开脚本管理器的控制面板，点击 **“新建脚本”**；
   - 将工作区中的 [`userscript/blockclip-to-zip.user.js`](./blockclip-to-zip.user.js) 全部内容复制并粘贴进去；
   - 按 `Ctrl + S` 保存。

## 💡 使用指南

| 场景 | 推荐操作 |
| :--- | :--- |
| **常规使用** | 点击页面右下角的 **📦 悬浮球** 展开面板，点击 **“📋 读取剪贴板”**（或 `Ctrl+V`），脚本将**自动解析并打包**；直接按住生成的卡片拖入聊天框，或点击 **“📎 一键添加到附件”**。 |
| **极速流** | 在 IDE 复制好代码后，切换到浏览器，直接 **右键点击悬浮球** 或按 **`Alt + Shift + Z`**，全自动读取打包并注入附件。 |
| **聊天框直粘** | 直接在聊天框按 `Ctrl+V` 粘贴多文件代码，点击底部弹出的 **`[ ⚡ 转为附件注入 ]`** 胶囊，代码自动转化为附件，并自动清理正文输入框。 |
| **大工程 / 避开限制** | 若项目包含十几个文件导致 Gemini 拒收 ZIP，点击面板顶部的 **`[ 📄 单文件 .md ]`** 模式，自动打包为单个 Markdown 上传。 |
| **本地备份** | 点击卡片下方的 **“💾 下载 ZIP / .md”**，直接保存到本地。 |
