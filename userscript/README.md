# BlockClip to ZIP 油猴脚本 (Tampermonkey Userscript) v3.1.1

专为 **Google Gemini** (`gemini.google.com`) 与 **Google AI Studio** (`aistudio.google.com` / `ai.dev`) 深度定制的代码还原、原生流式压缩打包与无闪烁秒传增强脚本。

---

## 🌟 核心特性

### 1. 📂 目录层级还原与零 CDN 原生流式压缩引擎
- **零外部依赖原生 DEFLATE 压缩**：内置浏览器原生 `CompressionStream('deflate-raw')` 流式压缩引擎（自动计算标准 CRC32 与 PKZIP 帧头），彻底摆脱第三方 CDN 依赖与沙箱卡死；不支持环境自动平滑降级为 `Native STORE`。
- **智能 Markdown 切割与切片合并**：精准提取 `File: path/to/file.ext` 及其自适应反引号围栏，自动还原深层目录结构，并将同一文件的多个片段（如 `lines 10-25`、`lines 50-80`）附带对应语言注释分隔合并入同一文件。
- **双导出模式随心切换**：
  - **📦 ZIP 压缩包模式**：自动还原完整目录树，适合 AI 理解项目工程结构。
  - **📄 单文件 .md 模式**：自动构建带 ASCII 目录树与自适应围栏的代码合集包，**绕过 Gemini 针对 ZIP 文件数量的上传限制**。

### 2. ⚡ 工具栏内嵌秒传 & 全程可视化进度 HUD
- **工具栏原生内嵌按钮**：直接在 Gemini / AI Studio 聊天输入框工具栏内嵌 **`📦 粘贴为ZIP`** / **`📄 粘贴为MD`** 按钮（若插槽不可用自动平滑退化为可拖动的悬浮按钮）。
- **三模式无闪烁附件投递**：
  - **⚡ 粘贴模式（默认，零闪烁）**：向主输入框直接派发合成文件 `ClipboardEvent('paste')`，零遮罩闪烁；
  - **📂 原生上传**：直接通过页面隐藏 `input[type="file"]` 触发上传；
  - **🔄 自动兜底**：通过 `MutationObserver` 实时校验附件挂载状态，自动在粘贴与原生上传间切换兜底。
- **全程可视化进度 HUD**：解析、压缩、上传每一阶段均有顶部毛玻璃进度条与百分比反馈。

### 3. 🚀 极速直通、聊天框智能感知与自由拖动
- **全键盘闭环**：
  - **`Alt + Shift + Z`**：无需展开面板，直接读取剪贴板 -> 解析打包 -> 秒传附件（与 IDE 插件 `Alt+Shift+S` / `Alt+Shift+X` 无缝衔接）。
  - **`Alt + B`**：一键展开 / 收起右侧 `ZIP 助手` 面板。
- **聊天框粘贴自动感知**：在对话框中直接粘贴多文件或大体积单文件 BlockClip 代码时，底部浮现 **`[ ⚡ 转为附件秒传 ]`** 胶囊（也可在偏好设置中开启“聊天框粘贴自动转附件”）。
- **侧边标签与面板上下自由拖动**：按住右侧 `ZIP 助手` 侧边标签或面板标题栏可任意上下拖动并持久化记忆位置；卡片文件名支持瞬时重命名。

### 4. 🛡️ 跨浏览器兼容与极致安全防线
- **100% 兼容 Chrome / Edge / Firefox**：通过 `@grant unsafeWindow` 与 `cloneInto` 穿透 Firefox Xray Vision 沙箱。
- **大文本内存直通**：文本超过 250 KB 自动走内存直通区，文本框仅渲染前 2400 字符预览，杜绝大文本 DOM 卡顿。
- **敏感文件识别与一键排除**：自动标出 `.env`、私钥、证书文件（保留 `.env.example` 等安全模板），支持在文件树中一键取消勾选排除。
- **100% 免疫 Trusted Types**：全量采用原生 DOM API 构建，零 `innerHTML`。

## 🚀 安装步骤

1. **准备浏览器脚本管理器**：
   确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)、[Violentmonkey](https://violentmonkey.github.io/) 或 [ScriptCat](https://scriptcat.org/)。
2. **安装脚本**：
   - 打开脚本管理器控制面板，点击 **“新建脚本”**；
   - 复制本目录下 [`blockclip-to-zip.user.js`](./blockclip-to-zip.user.js) 的全部代码并粘贴保存即可。

## 💡 使用指南

| 场景 | 推荐操作 |
| :--- | :--- |
| **极速秒传（最推荐）** | 在 IDE 用 BlockClip 复制好代码后，切到 Gemini / AI Studio，直接点击输入框旁的 **`📦 粘贴为ZIP`** 按钮或按 **`Alt + Shift + Z`**。 |
| **精细筛选与重命名** | 点击屏幕右侧 **`ZIP 助手`** 标签（或按 **`Alt + B`**）展开面板，勾选/排除文件、修改附件文件名，再点 **“⚡ 一键添加到附件”** 或 **“💾 下载”**。 |
| **聊天框直接 Ctrl+V** | 直接在对话框按 `Ctrl+V` 粘贴代码，点击底部弹出的 **`[ ⚡ 转为附件秒传 ]`** 胶囊（或在设置开启自动拦截转换）。 |
| **绕过 Gemini ZIP 限制** | 文件数量较多时，在面板顶部切换为 **`📄 单文件 .md`** 模式后秒传。 |
